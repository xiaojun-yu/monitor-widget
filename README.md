# 系统资源监控小组件

一个放在 Windows 屏幕左上角的轻量桌面悬浮组件。EXE 版本无需安装 Python 或依赖。

## 显示内容

- CPU 占用
- 内存占用百分比
- NVIDIA GPU 占用
- NVIDIA 显存占用百分比
- 基于 Intel PresentMon 的真实游戏 Present 帧率（优先识别英雄联盟，并自动识别硬件呈现的游戏）
- 实时下载（↓）和上传（↑）速度，单位为 KB/s 或 MB/s

## EXE 使用方式

- 双击 `显示监控.exe`：显示系统监控组件；重复点击不会重复创建组件。
- 双击 `关闭监控.exe`：精准关闭该组件，不会结束其他 Python 程序。
- 首次运行 `显示监控.exe` 后会自动加入当前用户的 Windows 开机启动项。

两个 EXE 均不依赖本机 Python 环境，也不会显示命令行窗口。

## 源码启动

安装 `psutil` 后，也可以双击 `启动监控.vbs`（无命令行窗口）或 `启动监控.bat`。

## 操作

- 小组件固定在屏幕左上角、永久置顶，并启用鼠标点击穿透。
- 通知区域托盘图标通常会进入任务栏的“隐藏图标”面板；双击可显示/隐藏组件。
- 右键托盘图标可切换显示/隐藏、移动到左上角或右上角，以及退出组件。
- 托盘和 EXE 使用 `assets/monitor_icon.ico` 自定义图标（来源：`扮鬼脸.svg`）。
- 托盘图标右键菜单可显示/隐藏或退出，也可使用 `关闭监控.exe` 退出组件。

## 兼容性

目前针对 Windows 10/11 和 NVIDIA 显卡。CPU 与内存无显卡依赖；未检测到 `nvidia-smi` 时 GPU 项会显示“不可用”。
